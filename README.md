# Excel Practical Problem Solving

A collection of practical Excel exercises completed while learning Microsoft Excel fundamentals and developing practical data-handling and problem-solving skills.

## About

This repository documents my hands-on practice with Microsoft Excel.

The exercises focus on using Excel to solve practical problems rather than simply learning individual features. Each project involves working with data, applying formulas or functions, organizing information, and producing useful results.
